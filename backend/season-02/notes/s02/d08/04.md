# Mongoose Schema Validation - using validator.js library


# Validator.js Notes

## What is Validator.js?

**Validator.js** is a JavaScript library used to validate and sanitize strings.

It is commonly used for validating:

* Email
* URL
* Password
* Mobile number
* UUID
* Credit card
* IP address
* Date
* Numeric values

---

## Installation

```bash
npm install validator
```

---

## Import

### CommonJS

```js
const validator = require("validator");
```

### ES Modules

```js
import validator from "validator";
```

# Common Validation Methods

## 1. Email Validation

```js
validator.isEmail("test@example.com");
```

Returns:

```text
true
```

Invalid example:

```js
validator.isEmail("test@");
```

Returns:

```text
false
```

### In Mongoose

```js
email: {
  type: String,
  required: true,
  validate(value) {
    if (!validator.isEmail(value)) {
      throw new Error("Invalid email address");
    }
  },
}
```

```js

      message: "Invalid user ID",
    });
  }

  // Continue with database operation
});
```

# Sanitization Methods

Validator.js can also clean data.

## 1. Trim

```js
validator.trim("  Hello World  ");
```

Result:

```text
"Hello World"
```

---

## 2. Normalize Email

```js
validator.normalizeEmail("TEST@GMAIL.COM");
```

Result:

```text
"test@gmail.com"
```

---

## 3. Escape HTML

```js
validator.escape("<script>alert('Hello')</script>");
```

Converts special HTML characters into safe entities.

# Using Validator.js in Mongoose

Example User Schema:

```js
const mongoose = require("mongoose");
const validator = require("validator");

const userSchema = new mongoose.Schema({
  name: {
    type: String,
    required: true,
  },

  email: {
    type: String,
    required: true,
    unique: true,
    lowercase: true,
    trim: true,
    validate(value) {
      if (!validator.isEmail(value)) {
        throw new Error("Invalid email address");
      }
    },
  },

  photoUrl: {
    type: String,
    validate(value) {
      if (value && !validator.isURL(value)) {
        throw new Error("Invalid photo URL");
      }
    },
  },

  age: {
    type: Number,
    min: 18,
    max: 100,
  },
});

const User = mongoose.model("User", userSchema);

module.exports = User;
```

# `throw Error` vs returning `true/false`

## Using `throw`

```js
validate(value) {
  if (!validator.isEmail(value)) {
    throw new Error("Invalid email");
  }
}
```

If invalid:

```text
Error is thrown
↓
Mongoose catches it
↓
Validation fails
```

## Using `validator` object

```js
validate: {
  validator(value) {
    return validator.isEmail(value);
  },
  message: "Invalid email address",
}
```

If the validator returns:

```text
true  → validation passes
false → validation fails
```

This is often a cleaner approach:

```js
email: {
  type: String,
  validate: {
    validator(value) {
      return validator.isEmail(value);
    },
    message: "Invalid email address",
  },
}
```

# Important Methods to Remember

| Method               | Purpose                    |
| -------------------- | -------------------------- |
| `isEmail()`          | Validate email             |
| `isURL()`            | Validate URL               |
| `isStrongPassword()` | Validate password strength |
| `isMobilePhone()`    | Validate phone             |
| `isMongoId()`        | Validate MongoDB ID        |
| `isInt()`            | Validate integer           |
| `isFloat()`          | Validate decimal number    |
| `isBoolean()`        | Validate boolean           |
| `isAlpha()`          | Only letters               |
| `isAlphanumeric()`   | Letters and numbers        |
| `isLength()`         | Validate string length     |
| `isEmpty()`          | Check empty string         |
| `trim()`             | Remove extra spaces        |
| `normalizeEmail()`   | Normalize email            |
| `escape()`           | Escape HTML                |

## Main takeaway

```text
validator.js
     ↓
Validates individual string values
     ↓
Returns true or false
     ↓
You decide what happens if validation fails
```

For your **Express + Mongoose project**, the most useful methods initially are:

```js
validator.isEmail()
validator.isURL()
validator.isMongoId()
validator.isStrongPassword()
```

These four will cover many common backend validation cases.
